# 星环疾驰

一个用 Three.js 写的 3D 跑酷小游戏：穿过星环、收集能量、躲开红色障碍。

## 运行

```sh
python3 -m http.server 8331 --directory "文档/狗头军师/有趣项目/3D星环疾驰"
```

浏览器打开 `http://127.0.0.1:8331/index.html`。

## 操作

- 桌面：方向键 / WASD 移动
- 手机：按住屏幕拖动
- `P` 或右下角按钮暂停

## 文件

- `index.html`：游戏本体（Three.js 从 CDN 加载）
- `shots/`：桌面和手机实测截图

已验证：桌面 1280×800、手机 390×844 均可运行，HUD 不重叠，无控制台错误。
